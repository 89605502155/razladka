## 1. Модель

В ряде из `n` точек с `K` разладками `K + 1` *участков*. Участок `k`
начинается с индекса `change_points[k - 1]` (0 при `k = 0`) и идёт до
`change_points[k]` (у последнего — до `n`), правая граница не включается.
`segments[i]` — номер участка точки `i`.

### 1.1 Где стоят разладки: марковское переключение режимов

Режим `r_t ∈ {0, …, K}` — цепь Маркова с левосторонней (верхней
двухдиагональной) матрицей переходов

```
      ⎡ 1−q   q    0   …   0 ⎤
      ⎢  0   1−q   q   …   0 ⎥
P  =  ⎢  ⋮              ⋱   ⋮ ⎥
      ⎢  0    …    0  1−q  q ⎥
      ⎣  0    …    0   0   1 ⎦
```

и минимальным пребыванием `m = 2` точки: режим `j < K` длится
`d_j = m + G_j`, `G_j ~ Geom(q)` (число неудач до первого успеха). Последний
режим поглощающий, поэтому у дошедшей до него цепи ровно `K` разладок. `q`
выбирается так, чтобы `E d_j = n / (K + 1)`:

```
q = 1 / (n / (K + 1) − m + 1)        (q = 1, если n / (K + 1) ≤ m)
```

Реализация, которая не дошла до последнего режима хотя бы с `m` точками в
запасе (`Σ d_j > n − m`), отбрасывается и разыгрывается заново — как в обзоре,
на который опирается библиотека. Условие успеха немного укорачивает принятые
режимы: при `n = 1000, K = 4` средняя длина около 160 вместо 200.

Требуется `n_points ≥ 2 · (n_change_points + 1)`; при `K = 0` ряд из одного
участка.

### 1.2 Гладкий каркас

У режима `j` дрейф `μ_j = σ_j · |μ_j|`, `|μ_j| ~ Uniform(0.5, 1.5)`. Знаки
`σ_j` чередуются, последний равен `last_trend` (случайный при `None`). Каркас

```
x_0 = 0,    x_i = x_{i−1} + μ_{segments[i]}
```

— непрерывная кусочно-линейная кривая: линейная (гладкая) внутри участка,
излом в точке разладки. Каркас аффинно, с положительным коэффициентом,
отображается на `[lower + A, upper − A]`: направления сохраняются, а гладкий
ряд касается обоих краёв этой полосы.

### 1.3 Негладкость: сумма Вейерштрасса — Мандельброта

**Коэффициент негладкости** `s ∈ [0, 1]` равен `s = D − 1`, где `D` —
фрактальная (клеточная) размерность графика: у гладкой кривой, например
синусоиды, `D = 1` (`s = 0`), у кривой, почти заполняющей плоскость, `D → 2`
(`s → 1`). Эквивалентно, `H = 1 − s` — показатель Гёльдера.

```
W(i) = Σ_{k=0}^{M} λ^{−kH} · cos(2π · λ^k · i / n + φ_k),
λ = 1.5,   M = ⌊log_λ(n / 2)⌋,   φ_k ~ Uniform(0, 2π)
```

Частоты идут от одного периода на весь ряд до частоты Найквиста. `W` делится
на `max |W|`, умножается на

```
A = s · roughness_scale · (upper − lower)
```

и прибавляется к каркасу. Каркас лежит в `[lower + A, upper − A]`, а
`|A · W / max|W|| ≤ A`, поэтому все значения попадают в `[lower, upper]`
без обрезки. Для этого нужно `s · roughness_scale < 0.5`.

`roughness_scale` (по умолчанию 0.1) — размер негладкой части при `s = 1` в
долях диапазона значений; `s` задаёт и рваность, и размер.

Оценка размерности `W` методом Хигучи совпадает с `1 + s` с точностью 0.1
при `s ∈ [0.2, 0.6]`; при `s = 0.8` она около 1.69 — это известное
занижение метода Хигучи вблизи `D = 2` на дискретных кривых (см.
`tests/test_roughness.py`).

### 1.4 Шкала времени

```
t_i = start + round(i · (end − start) / (n − 1))
```

считается точно, в целых числах. Границы можно задать в любом порядке: ряд
всегда идёт вперёд по времени, «последний» участок — самый поздний. Наивное
время считается UTC, время с часовым поясом переводится в UTC. Единица —
самая мелкая из `ns`, `us`, `ms`, `s`, в которой обе границы помещаются в
int64, а шаг не меньше одного тика (метки строго возрастают); иначе
`ValueError`.

| Пример | Единица |
|---|---|
| 10⁸ точек за сутки | `ns` |
| сегодня → 2008 | `ns` |
| 5 год н. э. → сегодня | `us` |
| миллион лет назад → сегодня | `ms` |
| миллиард лет назад → сегодня | `s` |

Границы: `datetime.datetime`, `datetime.date`, строки ISO 8601 (в том числе
с наносекундами и расширенным годом, например `-100000-01-01`),
`numpy.datetime64`, `pandas.Timestamp`. `end=None` — текущий момент.

### 1.5 Воспроизводимость

`seed` (`int` или `numpy.random.Generator`) передаётся в
`numpy.random.default_rng`. Одинаковые `seed` и параметры дают побитно
одинаковый ряд на одной платформе.

## 2. Память и скорость

Всё считается кусками: метки времени — точно в целых числах, сумма
Вейерштрасса — Мандельброта — блочными матричными произведениями (одна
таблица в несколько десятков мегабайт на все куски). Помимо результата
(16 байт на точку: время и значение) дополнительной памяти почти нет;
`segments` вычисляется при обращении и не хранится. На ноутбуке 10⁷ точек —
около 4 с и 250 МБ, 10⁸ точек — около 1.7 ГБ.

CSV, JSON, Excel, HDF5, NetCDF, Trosna и TsFile пишутся кусками. Для
Parquet, Feather и Arrow IPC строится одна таблица Arrow, это ещё одна копия
ряда в памяти.

## 3. Файлы

Все форматы перезаписывают существующий файл. Время — целое число `unit`
от 1970-01-01 UTC там, где формат хранит целые, и текст ISO 8601 UTC (`…Z`)
в CSV, JSON и Excel.

* **CSV** — заголовок `time,value,segment`; значения в кратчайшей точной
  записи.
* **JSON** — объект с `n_points`, `change_points`, `change_times`, `trends`,
  `roughness`, `unit` и массивами `time`, `value`, `segment`.
* **Parquet / Feather / Arrow IPC** — столбцы `time`
  (`timestamp[unit, tz=UTC]`), `value`, `segment`; разметка — JSON в
  метаданных схемы под ключом `razladka`.
* **HDF5** — датасеты `time` (int64, атрибуты `unit`, `epoch`), `value`,
  `segment`; атрибуты файла `change_points`, `change_times`, `trends`,
  `roughness`, `unit`, `razladka` (вся разметка в JSON).
* **NetCDF** (через h5netcdf, NetCDF-4) — измерение `time`; переменная
  `time` с CF-атрибутом `units = "<unit> since 1970-01-01T00:00:00Z"`,
  `value`, `segment`; те же глобальные атрибуты, что в HDF5.
* **NPZ** — массивы `time`, `value`, `segment`, `change_points`, `trends`,
  `roughness`, `unit`.
* **Excel** — лист `series` (`time` текстом ISO: даты Excel не умеют годы до
  1900 и наносекунды), лист `change_points` (участок, первый индекс, первый
  момент, направление), лист `info`. openpyxl пишет числа с 16 значащими
  цифрами, последний бит значения может отличаться. Не больше 1 048 575 точек.
* **Trosna** — устройство `series` со столбцами `value` (float64) и `segment`
  (int64) в выбранной единице; по аннотации на участок — от первой до
  последней метки участка, метка `up` / `down`, заметка `segment k`;
  метаданные файла `razladka.change_points`, `razladka.change_times`,
  `razladka.trends`, `razladka.roughness`, `razladka.unit`; один коммит.
  Файлы одинаково читаются pytrosna и эталонным Rust CLI `trosna`.
* **TsFile** (Apache TsFile 2.x, табличная модель) — таблица `series_<unit>`
  (например, `series_ns`: сам TsFile единицу времени не хранит), тег
  `segment` (по устройству на участок), поле `value`.

## 4. Оценка детектора

```python
import numpy as np

import razladka

s = razladka.generate(2_000, 4, start="2026-01-01", lower=0, upper=1, roughness=0.3, seed=0)

# наивный детектор: самые сильные изменения сглаженного наклона
slope = np.convolve(np.diff(s.values), np.ones(25) / 25, mode="same")
turns = np.abs(np.diff(np.sign(slope)))
found = np.sort(np.argsort(turns)[-4:]) + 1


def hits(truth: np.ndarray, found: np.ndarray, margin: int) -> int:
    return sum(bool(np.any(np.abs(found - t) <= margin)) for t in truth)


print(f"найдено {hits(s.change_points, found, margin=20)} из {s.n_change_points}")
```
